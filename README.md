# sprint2-frontend

## Fluxos

- **Fluxo 1 – Consultar alerta e local seguro (principal):** index.html → local-seguro.html.
  O morador consulta o alerta, informa o endereço, escolhe um abrigo e vê a rota demonstrativa.
- **Fluxo 2 – Registrar ocorrência:** index.html → ocorrencia.html → confirmacao.html.
  O morador informa tipo, local e dados opcionais e recebe uma confirmação de envio simulado.
- **Fluxo 3 – Gerenciar alertas e ocorrências:** index.html → autoridade.html.
  O agente da Defesa Civil escolhe a região, altera o risco simulado e verifica ocorrências.

A documentação completa (perfis, caminhos alternativos, pontos de falha e fluxogramas) está no PDF da entrega.
